# Struct e enum em C#

Projeto pequeno pra estudar a diferenca entre `enum`, `struct` e `class` em C#.
Tem um enum `DiaDaSemana`, um struct `Ponto` com um metodo pra calcular distancia
entre dois pontos, e uma classe `PontoClasse` igual ao struct so que como
tipo de referencia.

## O que pratiquei

- Declarar e usar um `enum`
- Declarar um `struct` com construtor e metodo
- Calcular distancia entre dois pontos (Pitagoras)
- Ver na pratica que struct copia valor e classe copia referencia

## Como rodar

```bash
dotnet run
```
